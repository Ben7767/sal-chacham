# 🛒 סל חכם – השוואת מחירים בסופרים

אתר להשוואת מחירים, מוצר אחרי מוצר, בין הרשתות הזולות בישראל: **רמי לוי, אושר עד ויוחננוף**. קרפור מוכנה בהגדרות.
נבנה ע"י **Tech4U**.

- חיפוש לפי שם, מותג או ברקוד, וסריקת ברקוד במצלמה ב-Chrome באנדרואיד
- המחיר של כל מוצר בכל רשת, כשהזול ביותר מסומן בירוק, ומבצעים שפתוחים לכולם
- סל קניות עם כמויות: סה"כ לכל רשת, הרשת המנצחת, וכמה יוצא אם קונים כל מוצר במקום הכי זול
- הסל נשמר בטלפון
- המחירים מתעדכנים אוטומטית כל בוקר

## איך זה עובד

```
GitHub Actions (כל יום)
  └─ scripts/download.py   מוריד קבצי PriceFull / PromoFull מהרשתות (חוק שקיפות המחירים)
  └─ scripts/build_data.py  מחשב מחיר לכל ברקוד בכל רשת  ->  site/data/prices.json
  └─ GitHub Pages           מפרסם את התיקייה site/
```

ההורדה נעשית עם ספריית הקוד הפתוח [il-supermarket-scraper](https://github.com/OpenIsraeliSupermarkets/israeli-supermarket-scarpers).

## העלאה לאוויר (פעם אחת)

1. צור ריפו חדש ב-GitHub (למשל `Ben7767/sal-chacham`) והעלה אליו את כל הקבצים.
2. ב-**Settings → Pages**, תחת **Source**, בחר **GitHub Actions**.
3. ב-**Actions**, בחר "עדכון מחירים ופרסום האתר" ולחץ **Run workflow**.
4. אחרי כ-10 דקות האתר יהיה זמין בכתובת `https://ben7767.github.io/sal-chacham/`.

## הגדרות – `config.json`

| שדה | מה זה |
|---|---|
| `max_stores_per_chain` | מכמה סניפים לכל רשת לקחת מחירים (ברירת מחדל 3) |
| `store_ids` | מספרי סניפים ספציפיים, למשל סניפים ליד הבית. אם הרשימה ריקה, נלקחים סניפים אוטומטית |
| `enabled` | הפעלה או כיבוי של רשת |

**קרפור:** האתר של קרפור חוסם גישה מחוץ לישראל, ושרתי GitHub נמצאים בחו"ל. לכן הרשת כבויה כברירת מחדל. כדי לכלול אותה, צריך להריץ את העדכון ממחשב בארץ:

```bash
pip install -r requirements.txt
python scripts/download.py rami osher yoh carrefour
python scripts/build_data.py
# ואז להעלות את site/data/prices.json לריפו
```

## בדיקה מקומית בלי אינטרנט

```bash
python tests/make_sample.py
python scripts/build_data.py tests/sample_dumps
cd site && python -m http.server 8000   # http://localhost:8000
```

## הערות

- מחיר הרשת הוא החציון בין הסניפים שנבדקו. המחיר בסניף שלך עשוי להיות שונה.
- ההשוואה כוללת רק מוצרים עם ברקוד שמופיעים בלפחות שתי רשתות. ירקות ופירות במשקל מקבלים בכל רשת קוד פנימי משלה, ולכן אי אפשר להשוות אותם.
- מבצעים לחברי מועדון בלבד לא נכללים. במבצע כמות (למשל "2 ב-20"), מחיר המבצע נספר רק כשבסל יש את הכמות הנדרשת.
